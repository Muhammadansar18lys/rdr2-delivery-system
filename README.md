## 🎯 Project Overview

This project simulates a Wild West delivery system in which Arthur Morgan and other customers receive packages containing different items.

The program organizes orders, sorts them by delivery distance, packs them into a bag, and processes deliveries using a conveyor belt.

## 🧠 Data Structures and Algorithms

- **Doubly Linked List:** Stores the items in each order.
- **Structures (`struct`):** Organize customer, address, distance, and item information.
- **Bubble Sort:** Sorts packages by descending numeric distance.
- **Stack (LIFO):** Stores up to three packages per bag.
- **Queue (FIFO):** Simulates the conveyor belt.
- **Pointers and Arrays:** Connect and manage the packages.
